# Zakaria Al Mokri - Personal Portfolio

A modern, high-performance personal portfolio showcasing my experience as a Software Engineer and IT Systems Manager. 

### Tech Stack
* **Framework:** React / TanStack Start
* **Language:** TypeScript
* **Styling:** Tailwind CSS

### Development Setup
To run this project locally:
1. Clone the repository: `git clone https://github.com/zakaria-mokri/zakaria-mokri.github.io.git`
2. Install dependencies: `npm install` (or `bun i`)
3. Start the development server: `npm run dev` (or `bun run dev`)
